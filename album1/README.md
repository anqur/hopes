# 未命名首张专辑

一张关于焦虑障碍（anxiety disorder）的专辑。

致志豪。

2026.03.07 Anqur

## 焦虑障碍

关于这个主题，Bedhead 乐队的首张专辑（debut）《[WhatFunLifeWas]》也同样拥有这个主题的体现。我也想尝试能写出点什么。

[WhatFunLifeWas]: https://numerogroup.com/products/bedhead-whatfunlifewas

## 简单的结构

本张专辑的每一首歌大多不超过 3 分钟，比较简短，这是受到 Madvillain 专辑《[Madvillainy]》以及 Duster 歌曲《[Shadows of Planes]》的影响，基本采用 1 段落、1.5 段落的形式，不想做太多的变换。

[Madvillainy]: https://en.wikipedia.org/wiki/Madvillainy
[Shadows of Planes]: https://youtu.be/WDtH__GYbrA?si=4eyBBrxEEjnKRsWz

## 松散的音乐

专辑整体的纯器乐歌曲偏多，形体松散，可能会更像是一个合集（compilation）专辑，会让我联想到 Valium Aggelein 的《[Black Moon]》。

[Black Moon]: https://numerogroup.com/products/valium-aggelein-black-moon

## 琶音

虽然专辑大量地使用 Duster 式的琶音（arpeggio），但我还是十分惊叹于 Radiohead 在《[Jigsaw Falling Into Place]》中对琶音的运用。我不知道怎样才能写出这样的歌。

[Jigsaw Falling Into Place]: https://youtu.be/GoLJJRIWCLU?si=Vr5__b85JhGXDvl6
